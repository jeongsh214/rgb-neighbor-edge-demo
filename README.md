# 수학으로 살펴보는 AI 이미지 분석 · A / B / C

한 픽셀의 RGB값과 주변 8개 픽셀의 채널별 평균을 비교해 윤곽 **후보 점수**를 계산하는 교육용 예제입니다. 후보를 살펴보고 윤곽·비윤곽을 직접 표시하여 학습 자료로 내보낼 수 있습니다.

- [A · 윤곽 정답 자료 만들기](https://jeongsh214.github.io/rgb-neighbor-edge-demo/)
- [B · 정답으로 작은 MLP 학습하기](https://jeongsh214.github.io/rgb-neighbor-edge-demo/train.html)
- [C · PCA로 이미지의 주요 방향 찾기](https://jeongsh214.github.io/rgb-neighbor-edge-demo/pca.html)

각 페이지 상단 메뉴에서 A·B·C를 오갈 수 있습니다. 페이지마다 개념 설명과 실제로 조작할 수 있는 예제가 함께 있습니다. A에서 만든 JSON은 B에서 학습 자료로 사용할 수 있습니다. C는 별도의 이미지 자료로 방향 분석과 차원 축소를 실습합니다.

## C · PCA와 EigenFaces 방식의 차원 축소

`pca.html`을 열면 직접 만든 얼굴 그림 12장을 자동으로 분석합니다. **남길 주요 방향**을 0개부터 끝까지 바꾸며 원본·복원·절대 차이, 사영 좌표, 변동 보존율과 복원 RMSE를 비교할 수 있습니다. 예제는 사진이 아닌 합성 얼굴 그림입니다.

1. 예제 얼굴 중 하나를 고르거나 **내 이미지 여러 장 선택**으로 2~24장의 이미지를 선택합니다. 파일당 10MB 이하 PNG·JPEG·WebP·BMP를 지원합니다.
2. 중앙 정사각형을 자르고 32×32 흑백으로 맞춥니다. 투명 부분은 흰 배경에 합성합니다. 얼굴·눈의 위치는 미리 직접 맞춰 주세요. 자동 얼굴 탐지·정렬은 하지 않습니다.
3. 각 이미지를 1024개 픽셀 값으로 표현하고, 자료 전체에서 같은 위치 픽셀의 평균을 뺍니다.
4. 고윳값이 큰 방향부터 골라 사영합니다. 남긴 좌표 수를 바꾸면 같은 좌표로 복원한 이미지도 바뀝니다. 0개에서는 평균 이미지만 남습니다.
5. **분석에 쓰지 않은 이미지 적용**은 기존 평균·방향을 그대로 사용합니다. 새 이미지는 분석 자료에 추가하지 않습니다.
6. 복원 결과는 PNG, 분석 자료의 현재 사영 좌표와 RMSE는 CSV로 저장할 수 있습니다.

리포트의 네 점 `(-2,-1), (-1,-2), (1,2), (2,1)` 예제도 함께 있습니다. 사영 방향을 돌려 제곱합이 45°에서 18, 135°에서 2가 되는지 확인합니다. 네 점의 `X^T X = [[10,8],[8,10]]`, 고윳값 `18, 2`, 주요 방향 `(1,1)/sqrt(2)`는 실제 수치 계산과 비교하여 검증합니다.

이미지의 `X`는 N×1024입니다. 계산량을 줄이기 위해 작은 `XX^T`의 대칭 고유분해(Jacobi 회전)를 구하고, 0이 아닌 고윳값에 대해 `u = X^T a / sqrt(lambda)`로 픽셀 공간의 주요 방향을 복원합니다. 이는 `X^T X`의 주요 방향과 같으며, 작은 점 예제에서는 직접 `X^T X`를 사용합니다. 이미지 N장을 평균 중심화하면 방향은 최대 N−1개이며, 최대 고윳값의 1e−10 이하인 매우 작은 방향은 수치 오차를 고려해 제외합니다.

고윳값은 중심화한 사영 좌표의 **제곱합**입니다. 표본분산으로 나타내려면 N−1로 나눕니다. 변동 보존율은 자료 전체의 남긴 제곱합 비율이고, 얼굴 인식 정확도나 원본 파일 크기 압축률이 아닙니다. 좌표 수 이외에 평균·공통 방향의 저장 비용이 있습니다. RMSE는 표시용 반올림·0~255 제한 전 복원값으로 계산합니다. 방향 이미지의 대비는 보기 쉽게 키우며, 원본과 복원 이미지에는 같은 0~255 밝기 범위를 사용합니다.

이 실습은 EigenFaces 방식의 방향 분석을 체험하며, 사람의 신원을 판단하거나 얼굴 인식 성능을 평가하지 않습니다. ViT 논문 4.5절·Figure 7의 대상은 **학습한 패치 임베딩 필터**입니다. 여기서는 이미지에 PCA를 적용하므로 해당 필터의 실제 재현 결과와 구분합니다. [ViT 원문](https://arxiv.org/html/2010.11929v2#S4.SS5), [PCA 공식 설명](https://scikit-learn.org/stable/modules/generated/sklearn.decomposition.PCA.html).

이미지·계산 결과는 브라우저 메모리 안에만 있으며 서버로 전송하지 않습니다. 새로고침하면 사라집니다. 외부 이미지·라이브러리 다운로드도 필요 없습니다.

## B · 실제 MLP 학습과 새 이미지 예측

`train.html`을 열고 **학습 시작**을 누르면 준비된 도형 3장으로 실제 가중치를 학습하고, 학습에 쓰지 않은 다른 도형 1장으로 평가합니다. 정답은 알려진 도형 영역의 경계(서로 다른 영역의 픽셀이 8이웃에 있는 위치)로 만듭니다. 윤곽 점수 임계값을 정답으로 사용하지 않습니다. 도형 표면의 줄무늬는 비윤곽 정답입니다.

내 자료를 사용하려면:

1. A에서 원본 이미지마다 **윤곽과 비윤곽**을 직접 표시하고 **학습 JSON 저장**을 누릅니다.
2. B에서 **자료 비우기 → A의 학습 JSON 추가**로 파일을 불러옵니다. 여러 장을 추가할 수 있습니다.
3. 원본 이미지 단위로 용도를 **학습 / 평가 / 미사용**으로 지정하고 **학습 시작**을 누릅니다. 한 장만 있으면 학습은 가능하지만 별도 평가 결과는 제공하지 않습니다.
4. 손실과 실제 가중치가 바뀌는 것을 확인한 뒤 **새 이미지로 예측**합니다.
5. **학습한 모델 JSON 저장**으로 가중치와 입력 변환을 저장합니다. 나중에 불러와 다시 학습하지 않고 예측할 수 있습니다. **예측 PNG 저장**도 지원합니다.

입력은 RGB 3개, 주변 채널별 평균 3개, A의 차이 점수 1개입니다. 원본 PNG와 정답 마스크로부터 특징을 다시 계산하며 JSON의 `samples`나 임계값으로 정답을 만들지 않습니다. RGB와 평균은 255로, 점수는 195075로 나누고 **학습에 사용한 샘플만**의 평균·표준편차로 표준화합니다. 표준편차 하한은 0.001, 표준화 값 제한은 ±8입니다. 같은 변환을 예측에도 적용합니다.

모델은 **7 → 12 → 1**, 은닉층의 GELU(tanh 근사), 출력의 sigmoid로 구성합니다. 이진 교차 엔트로피 손실을 연쇄법칙으로 미분해 모든 가중치와 편향을 Adam으로 조정합니다. 배치 크기는 64이고, 각 종류 최대 2,000개씩 같은 수를 뽑아 최대 4,000개로 학습합니다. 초기화와 추출은 재현 가능한 고정 시드를 사용합니다. 새로 학습을 시작하면 모델을 처음부터 만듭니다. **학습 중단**은 현재까지 조정한 모델을 남깁니다.

```text
z = W1 x + b1
h = GELU(z)
t = W2 h + b2
p = sigmoid(t)
L = -y log(p) - (1-y) log(1-p)

dL/dt = p-y
dL/dW2 = (p-y) h^T
dL/dz = W2^T (p-y) * GELU'(z)
dL/dW1 = (dL/dz) x^T
```

평가는 평가 이미지의 유효한 정답 픽셀 전체에서 수행합니다. 미지정은 음성으로 취급하지 않습니다. 같은 픽셀 원본은 이름을 바꿔도 학습/평가에 중복 지정할 수 없습니다. 같은 원본의 JSON을 다시 추가하면 기존 정답을 교체합니다. 평가용 원본은 가중치와 표준화 통계 계산에서 제외합니다. 평가 결과를 보며 임계값을 고르면 그 자료는 최종 시험 자료가 아니므로 실제 성능 확인에는 별도 시험 이미지가 필요합니다.

도형 예제는 같은 종류의 간단한 자료에서 학습 과정을 확인하기 위한 것입니다. 실제 사진에서의 일반적인 윤곽 성능이나 ViT의 성능을 나타내지 않습니다. 이 MLP는 각 픽셀의 7개 특징만 보므로, 그 특징에 없는 물체의 형태와 의미를 구분하는 데 한계가 있습니다. **ViT 전체나 Transformer를 학습하는 구현은 아닙니다.** 모델 출력은 분류 점수이며 보정된 확률을 보장하지 않습니다.

학습 JSON은 파일당 64MB, 최대 20장, 모델 JSON은 1MB까지 지원합니다. JSON 이미지는 최대 1024×1024픽셀에 해당하는 1,048,576픽셀까지 지원합니다. 새 예측 이미지는 최대 30MB이며 긴 변을 512픽셀 이하로 축소합니다. 원본과 정답 좌표를 맞추기 위해 학습 JSON 이미지는 다시 축소하지 않습니다. 완전 투명·유효 이웃 없음은 학습/평가/예측에서 제외합니다. 모든 처리는 브라우저 안에서 이루어지고 사용자 이미지나 모델을 서버로 전송하지 않습니다.

## 계산 규칙

픽셀 (i,j)의 주변 3×3 영역에서 중심을 제외한 유효한 이웃을 모읍니다. 보통 8개이며 테두리에서는 더 적습니다. 이미지 밖과 알파가 0인 완전 투명 픽셀은 제외합니다. **검정 (0,0,0)은 포함**하고, 알파가 0보다 큰 픽셀은 포함합니다. 평균은 실제 유효 이웃 수로 나눕니다.

```text
mean_R = sum(neighbor_R) / valid_neighbor_count
mean_G = sum(neighbor_G) / valid_neighbor_count
mean_B = sum(neighbor_B) / valid_neighbor_count

score = (R-mean_R)^2 + (G-mean_G)^2 + (B-mean_B)^2
candidate = valid_pixel && neighbor_count > 0 && score > threshold
```

모든 계산은 원본 RGB를 읽어서 수행합니다. 이전 픽셀의 계산 결과를 다음 평균에 넣지 않습니다. JavaScript의 실수 연산으로 차이를 구하므로 unsigned 8비트의 뺄셈·제곱 오버플로를 피합니다. 8비트 RGB에서 점수 범위는 0~195075입니다. 유효 이웃이 없는 픽셀은 점수를 0으로 두고 후보·평가·학습 샘플에서 제외합니다.

## 행렬곱 pE와의 연결

한 채널의 중심을 포함한 3×3 값을 행 순서로 펼친 p에 다음 가중치를 곱하면 중심과 주변 평균의 차이를 얻습니다.

```text
p = [x00, x01, x02, x10, x11, x12, x20, x21, x22]
E = [-1/8, -1/8, -1/8, -1/8, 1, -1/8, -1/8, -1/8, -1/8]^T
d = pE = center - mean(neighbors)
score = d_R^2 + d_G^2 + d_B^2
```

이는 8개 이웃이 모두 유효할 때의 식입니다. 테두리·투명 픽셀이 있으면 실제 유효 이웃 수 n에 맞춰 각 유효 이웃 가중치를 -1/n으로 바꿉니다. 제곱은 별도의 비선형 연산입니다. 전체 score를 하나의 고정된 E에 의한 선형변환이라고 설명하지 않습니다. 실제 코드는 큰 행렬을 만들지 않고 동일한 가중합을 이웃 루프로 계산합니다.

## 평균 상쇄 예제

**평균 상쇄 예제** 버튼은 다음 3×3 이미지를 보여줍니다. 숫자는 R=G=B인 회색조 값입니다.

```text
  0    0    0
  0  100  200
200  200  200
```

중심 주변의 검정 4개와 200인 픽셀 4개의 평균은 100입니다. 중심도 100이어서 점수는 0입니다. 이웃 각각과 차이가 있어도 평균에서는 상쇄될 수 있다는 한계를 직접 확인할 수 있습니다.

## 정답 표시와 평가

자동 후보와 사람이 표시한 정답은 분리되어 있습니다. 임계값을 바꿔도 정답은 바뀌지 않습니다.

| 내부 라벨 코드 | 의미 |
| --- | --- |
| 0 | 미지정: 평가와 학습 샘플에서 제외 |
| 1 | 사람이 표시한 윤곽 |
| 2 | 사람이 표시한 비윤곽 |

표시한 픽셀에서만 정밀도·재현율·F1을 계산합니다. TP는 맞춘 윤곽, FP는 비윤곽을 후보로 선택한 경우, FN은 놓친 윤곽입니다. 분모가 0이어서 정의할 수 없는 지표는 `—`로 표시합니다. 같은 이미지에서 임계값을 조정한 결과는 일반화 성능이 아닙니다. 실제 모델을 학습한다면 원본 이미지 단위로 학습·검증·테스트를 분리하고 양성과 음성을 함께 검토하세요.

## 학습 JSON

`reviewed-edge-dataset.json`의 스키마는 `rgb-neighbor-edge/v1`입니다.

- `image`: 작업 이미지 크기, 원본 크기, 원본 작업 이미지의 PNG data URL. 라벨을 덧그린 화면이 아닌 원본입니다.
- `config`: 계산 규칙과 임계값. 임계값은 후보 표시용이며 정답 생성에 쓰이지 않습니다.
- `labels.mask`: 행 우선 순서의 내부 라벨 코드 배열. 미지정은 비윤곽이 아닙니다.
- `samples`: 직접 표시한 유효 픽셀만 포함합니다. x, y, rgb, neighbor_mean, neighbor_count, score, label을 저장합니다. **samples의 이진 label은 윤곽 1 / 비윤곽 0**이며 내부 mask 코드와 다릅니다.

라벨 PNG는 흰색 255=윤곽, 검정 0=비윤곽, 회색 128=미지정입니다. 완전 투명하거나 유효 이웃이 없는 위치는 알파가 0입니다. 후보 PNG의 흰색은 **자동 후보**이므로 정답 PNG와 혼동하지 마세요.

A 페이지는 특징 추출, 수치 확인, 수동 라벨링과 학습 자료 내보내기를 다룹니다. B 페이지에서 이 자료로 실제 MLP를 학습할 수 있습니다. 학습 자료의 이미지는 사용자 파일일 수 있으므로 GitHub에 올릴 때는 직접 선택하고 검토하세요.

## 범위와 참고

색 차이가 크다고 실제 물체 경계라는 보장은 없습니다. 그림자·질감·노이즈도 높은 점수를 만들 수 있습니다. 이 방법은 방향별 이미지 기울기를 계산하는 Sobel이나, 여러 단계의 경계 선택을 하는 Canny와 동일하지 않습니다.

- [ViT 논문 3.1절](https://arxiv.org/html/2010.11929v2#S3.SS1): 패치의 선형 임베딩과 연결하는 수학적 배경입니다. 이 예제의 윤곽 점수는 ViT 논문이 제안한 알고리즘이 아닙니다.
- [OpenCV Sobel 설명](https://docs.opencv.org/4.x/d2/d2c/tutorial_sobel_derivatives.html)
- [OpenCV Canny 설명](https://docs.opencv.org/4.x/da/d22/tutorial_py_canny.html)

사용자가 제안한 RGB 점수 식을 바탕으로 AI의 구현 도움을 받아 만든 교육용 예제입니다. 실제 데이터에서 기존 방법보다 우수하다는 주장은 하지 않습니다.
